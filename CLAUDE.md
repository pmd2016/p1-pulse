# Instructions for Claude

## Branches

Every branch gets a human-readable name that says what the work is, in lowercase words separated
by hyphens: `solar-backfill-fix`, `p1mon-backup-restore-scripts`. Never use generated names such
as `claude/trusting-wozniak-tveoos`.

If a session starts on a generated branch name, rename it before the first push — or, when it was
already pushed, push under the readable name and delete the generated one from `origin`.
